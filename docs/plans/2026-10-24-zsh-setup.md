# zsh setup plan

Status: in progress. The repo side is built (steps 1, 2, 4 and 5 below): config, the `~/.zshrc` source-line script, drift check, Ghostty font, docs and tests. Nothing has been applied to this Mac yet; the live steps remain, each with its own approval.

## Decisions (operator, 2026-10-24)

- Keep oh-my-zsh, trimmed: `ZSH_THEME=""`, `plugins=()` (drop the git plugin; its shortcuts aren't used), auto-update off (`zstyle ':omz:update' mode disabled`). Measured: oh-my-zsh costs ~50 ms; nvm costs ~600 ms of the ~700 ms startup.
- Prompt: Starship with a Catppuccin Mocha palette: folder (mauve), git branch (peach) and status, last command duration, Node/Python version only when relevant, `❯` green / red on error.
- History and suggestions: zsh-autosuggestions (grey ghost text, → accepts) + fzf (Ctrl+R history, Ctrl+T files, Alt+C folders), Catppuccin colours, `fd` as the file source.
- Extras: zoxide (`z`, `zi`), fzf-tab (fuzzy Tab menu with previews, case-insensitive completion), eza (`ls` with git status and tree; icons via JetBrains Mono Nerd Font, so switch Ghostty's `font-family` to `JetBrainsMono Nerd Font`), zsh-syntax-highlighting with Catppuccin's theme (vendor it, MIT, pinned commit).
- Node: switch from nvm to fnm (`fnm env --use-on-cd`), chosen over lazy-loading nvm.

## Layout

- Tracked `home/dot_config/zsh/dotfiles.zsh` holds everything: oh-my-zsh settings and load, history options, completion styles, fzf-tab, fzf, zoxide, fnm, eza aliases, autosuggestions, syntax highlighting (last), then `starship init zsh`.
- Tracked `home/dot_config/starship.toml`.
- `~/.zshrc` stays untracked (it holds an API key, pnpm and antigravity PATH lines). It keeps only those private lines plus one owned line sourcing `~/.config/zsh/dotfiles.zsh`. A `run_onchange_after_` script ensures that source line exists (marker block); drift reports it missing. The one-time cleanup of the oh-my-zsh and nvm lines in `~/.zshrc` is done by hand with a backup, and RUNBOOK covers a new Mac.
- Load order matters: oh-my-zsh (runs compinit) → fzf-tab → fzf → zoxide → autosuggestions → syntax highlighting → starship.
