# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Useful reports include the affected file (script, hook or chezmoi template), the platform (macOS or Linux), and steps to reproduce.

## Supported versions

This repository has no releases. Fixes land on `main` only; update your checkout and re-apply it to pick them up.
